# Phase 16: CLI Build & Export Commands

## Objective

Implement the `report build` and `report export` CLI commands. `report build` is the primary user workflow -- it takes a report config file and produces a complete report. `report export` converts datasets between formats.

## Why This Phase Is Sixteenth

With the Builder (Phase 13) and Output Adapters (Phases 14-15) complete, the core pipeline is functional. The CLI `build` command is the primary user-facing entry point and completes the first full end-to-end workflow.

### Task 16.1: Implement the `build` Command

**File to create:** `/Volumes/SecondDrive/code2/pygramattic-reports/src/pygramattic_reports/cli/build_cmd.py`

**Description:** The `report build` command takes a report config YAML file and produces one or more report files.

**Interface:**
```
report build <config_path> [OPTIONS]

Arguments:
  config_path    Path to report_config.yaml

Options:
  --output-format, -o    Override output format(s) (can be repeated: -o md -o docx)
  --output-dir            Override output directory
  --no-ai                Disable AI-generated sections (use placeholders)
  --dry-run              Show what would be generated without writing files
  --template             Override template name
  --theme                Override theme name
```

**Workflow:**
1. Load the report config YAML
2. Load application config
3. Initialize storage manager
4. Load the build config (resolve template, theme, datasets)
5. Build the report via `ReportBuilder`
6. For each output format:
   a. Get the output adapter from the registry
   b. Render the report
   c. Save to the output directory
7. Save the build log alongside the report
8. Print summary with file paths

**Example usage and output:**
```
$ report build report_config.yaml -o md -o docx

  Template: quarterly_report
  Theme: corporate_blue
  Datasets: main_data (150 rows)

  ✓ Revenue Distribution (bar chart)

  ✓ Detailed Analysis (placeholder - AI disabled)
  ✓ Full Dataset (data table)

Generating outputs...
  ✓ data/reports/abc12345/report.md
  ✓ data/reports/abc12345/report.docx
  ✓ data/reports/abc12345/build_log.json
```

### Task 16.2: Implement the `export` Command

**File to create:** `/Volumes/SecondDrive/code2/pygramattic-reports/src/pygramattic_reports/cli/export_cmd.py`

**Description:** The `report export` command converts a stored dataset to a different format (JSON, CSV, SQL).

**Interface:**
```
report export <dataset_id> --format <format> [OPTIONS]

Arguments:
  dataset_id    ID of the dataset to export (from 'report list datasets')

Options:
  --format, -f     Output format: json, csv, sql (required)
  --output, -o     Output file path (default: stdout)
  --dialect        SQL dialect: postgresql, sqlite (for SQL format)
  --layout         JSON layout: records, columnar (for JSON format)
  --delimiter      CSV delimiter (for CSV format)
```

**Example:**
```
$ report export abc12345 --format json --output data/exports/sales.json
✓ Exported dataset abc12345 to data/exports/sales.json (JSON, 150 rows)

$ report export abc12345 --format sql --dialect postgresql
-- Generated by pygramattic-reports
CREATE TABLE q4_sales (
    region TEXT,
    revenue DOUBLE PRECISION,
    ...
);
INSERT INTO q4_sales ...
```
